# Bridge Page Specification

## Overview
- Target file: `bridge.html`
- Source: `https://www.albatrossprotocol.com/bridge`
- Interaction model: static form with clickable amount states.

## DOM Structure
- Fixed app header with logo, product nav, active Bridge pill and Home pill.
- Main area with centered title and subtitle.
- Centered bridge widget with corner marks, amount grid, fee note, destination input, orange CTA and assurance row.
- Minimal footer with legal/community links and risk copy.

## Visual System
- Background: black with subtle violet radial glow.
- Widget: almost-black panel, thin gray border, square-ish 8px radius.
- Active nav: rounded gray pill.
- Amount buttons: dark cards, white amount, muted mono SOL label.
- CTA: full-width orange gradient rectangle with warm glow underneath.
