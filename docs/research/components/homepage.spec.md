# Homepage Specification

## Overview
- Target files: `index.html`, `styles.css`, `script.js`
- Screenshot reference: captured via Opera browser connector at 1440px.
- Interaction model: fixed nav, hover states, reveal-on-scroll, chart toggle.

## Extracted Visual System
- Background: black with subtle violet radial glow.
- Foreground: white headings, muted gray body copy.
- Accent: orange CTA, violet protocol badges and card borders.
- Typography: heavy geometric sans for headings, mono uppercase for labels.
- Shape language: large pill CTAs, 18-28px dark cards, thin violet/white borders.

## Text Content
All visible page content was copied from the original accessibility tree, with source-brand naming renamed to Ghost Protocol.

## Responsive Behavior
- Desktop: nav centered, hero two columns, product/roadmap grids.
- Tablet: fewer columns, tighter spacing.
- Mobile: nav links hidden, hero and feature sections stack, headline scales down.
